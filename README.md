# Gadget Hub – Sales Analytics Dashboard

## Project Overview

This project presents an interactive sales analytics dashboard for Gadget Hub, an electronics retail business. It was developed using Microsoft Power BI to analyze sales performance, profitability, product performance, customer segments, and store-level results for the year 2025.

## Tools & Technologies

- Microsoft Power BI
- Power Query – Data cleaning and transformation
- DAX – Measures and calculations

## Data Model

The project uses a relational data model consisting of five tables:

- Sales
- Calendar
- Products
- Stores
- Customers

The tables were connected using relationships to support interactive analysis.

## Key Performance Indicators

The dashboard tracks six key metrics:

- Total Revenue
- Total Cost
- Total Profit
- Profit Margin %
- Total Orders
- Average Order Value

## Dashboard Features

- Monthly revenue trend analysis
- Revenue comparison across product categories
- Store-wise profit analysis
- Customer segment contribution
- Product performance table with conditional formatting
- Interactive slicers for Quarter, Region, and Category

## Key Insights

- Computing and Audio are leading revenue-generating categories.
- Monthly revenue trends show a seasonal increase during October–December.
- The dashboard enables comparisons of profitability across stores and product performance across categories.
